# Hassan Raza

PhD researcher in Computing Science at the University of Aberdeen, working on machine learning, representation learning and explainability.

## Courses and code

| Repository | What you can study |
| --- | --- |
| [Machine Learning](https://github.com/HRtech-lab/MachineLearning) | 105 notebook-based examples covering supervised and unsupervised learning, diffusion, reinforcement learning, game theory and explainability. |
| [Representation Learning](https://github.com/HRtech-lab/Representation-Learning) | 11 self-supervised learning labs, including image and video JEPA variants, SimCLR, DINO and masked autoencoding. |
| [Transformers](https://github.com/HRtech-lab/Transformers) | 15 experiments on token representations, attention, transformer architectures and mixtures of experts. |
| [Computer Vision](https://github.com/HRtech-lab/Computer-Vision) | Eight image and video labs on edges, classification, segmentation, tracking and optical flow. |
| [Weight Space Programming](https://github.com/HRtech-lab/Weight-Space-Programming) | 13 labs on constructing, generating, editing, aligning and merging model parameters. |
| [Programming Languages](https://github.com/HRtech-lab/Programming-Languages) | 72 lessons across Python, Rust, R, C, C++, MATLAB, JavaScript, Go and SQL, with native programs and checked outputs. |
| [Cybersecurity](https://github.com/HRtech-lab/Cybersecurity) | Ten defensive computing labs on integrity, authentication, access reviews, monitoring and recovery. |
